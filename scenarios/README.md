## Runtime, interruption and changing conditions

- A valid structured answer marked max_tokens, or a tool call marked end_turn: reject before release/dispatch, retain original response/usage. Empty, malformed, oversized, unsupported and mixed answer/read content also fails. Invalid structured output has no automatic repair attempt.
- Provider failure after a source fetch: retain that read, HTTP error/body/request ID and failed-attempt measurements; no successful answer. A failed run is not an insufficient policy judgment.
- Change source bytes during planning: refuse the stale answer and record initial/final hashes. Reload the corpus for a later invocation. The agent never overwrites the changed file.
- CLI SIGINT/SIGTERM, async cancellation or deadline: close owned clients and preserve available failed-run observations. Forced termination may leave a running receipt. Local closure does not prove provider computation/billing stopped.
- Receipt write failure: stop further reads/network/release. If final publication also fails, inspect in-memory evidence_error and the last file; no durable completion is claimed.
- Concurrent read-only invocations: independent clients/fetched sets/receipts share only immutable source data. Cancelling one must not cancel or contaminate another.
- Missing/partial/invalid/zero usage: retain raw field presence separately from normalized SDK messages. Include failed measurements, keep cost unknown, and do not count raw/SDK observations as separate model executions.

A fresh invocation resets agent state; edited conditions use separate private copies. Stop owners before replacing sources. Receipts, provider retention/billing and caller-owned resources are separate reset boundaries. Source eligibility is an exact check; prose entailment, conflict reasoning and hostile-text behavior remain semantic questions. Controlled HTTP/CLI responses prove execution boundaries, not Claude quality. Model-free clarification and replayed/reassessed evidence are not fresh model trials. Live model comparisons, paid repetitions and persisted Firedrill cases await their external gates.
